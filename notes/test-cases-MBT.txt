| Categorie                    | Eigenschap                                    | Voorbeeldtest / invariant                                                                        | Moeilijkheid                                                                                  |
| ---------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| 🛡 **Privacy**               | Geen raw features gedeeld                     | "Er is nooit een actie waarin een featurewaarde (bv. 'Age=23') via het netwerk verstuurd wordt." | **Makkelijk**<br>Modelleer dat alleen *activations* verstuurd worden                          |
| 🛡 **Privacy**               | Labels blijven bij active client              | "Geen enkele passive client ontvangt een label of loss-waarde."                                  | **Makkelijk**<br>Verifieer dat alleen de server `compute_loss()` uitvoert                     |
| ✅ **Correctness**            | Elke trainingronde verlaagt loss              | "Na elke ronde is de loss ≤ vorige loss (binnen ε-tolerantie)."                                  | **Middel**<br>Loss moet gelogd worden per ronde                                               |
| ✅ **Correctness**            | Elke client krijgt alleen zijn eigen gradient | "De gradient voor Client A wordt alleen naar Client A gestuurd."                                 | **Makkelijk**<br>Modelleer `send_grad_to(client_id)` acties                                   |
| 🧩 **Bijdrage**              | Passieve clients dragen bij                   | "Zonder activatie van Client B wordt geen volledige loss berekend."                              | **Middel**<br>Verifieer dat `compute_loss` enkel mogelijk is na activaties van *alle* clients |
| ⛓ **Synchronisatie / flow**  | Volgorde van stappen is juist                 | "Loss kan alleen berekend worden nádat alle activations zijn binnengekomen."                     | **Makkelijk**<br>Gebruik state-checks in je MBT-model                                         |
| ❌ **Dropout / verstoringen** | Client valt uit voor ronde 2                  | "Als een client stopt met sturen, moet het protocol stoppen of foutmelding geven."               | **Moeilijker**<br>Alleen doen als tijd over is                                                |
| 🔁 **Convergentie** (optie)  | Model convergeert in < N rondes               | "Binnen 10 rondes moet accuracy > X% zijn."                                                      | **Middel tot moeilijk**<br>Alleen als je Flower goed kunt loggen                              |
